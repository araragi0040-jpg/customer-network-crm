# Connect CRM v004

個人事業主向けの「人脈管理 × 見込み顧客管理」モックです。

## v004でできること

- 人物の登録・編集・削除
- 出会った日、出会いのきっかけの記録
- 紹介元の記録
- 人物メモ
- 1人に複数サービス候補を設定
- サービスごとに「高 / 中 / 低」の優先度を設定
- 次回アクションと日付の登録
- 次回アクションの完了チェック
- ダッシュボード表示
- 人物検索・出会いのきっかけ絞り込み
- サービス・優先度別のクライアント候補表示
- 関係マップ表示（選択した人物の紹介元・紹介先を可視化）
- ブラウザの `localStorage` にデータ保存

## v003で追加したUI/機能

- サイドメニューに **関係マップ** を追加
- 人物ごとに **マップ** ボタンを追加
- 選択した人物を中心に、
  - 左側：紹介元チェーン
  - 右側：紹介先ツリー
  をマインドマップ風に表示
- 直接の紹介先人数、紹介先合計人数を表示

## GitHub Pagesで公開する方法

1. このフォルダ内のファイルをGitHubリポジトリへアップロード
2. GitHubのリポジトリで `Settings`
3. `Pages`
4. `Build and deployment` の `Source` を `Deploy from a branch`
5. Branchを `main`、Folderを `/(root)` に設定
6. `Save`

数分後、GitHub PagesのURLでそのまま表示できます。

## ローカルで確認する方法

`index.html` をブラウザで直接開いても基本動作します。

VS Codeを使う場合は、Live Serverなどの簡易サーバーで開くと確認しやすいです。

## データについて

v004はDBを使わず、ブラウザの `localStorage` に保存します。

そのため、

- 同じブラウザ・同じ端末では保存される
- 別端末とは同期されない
- ブラウザデータを削除すると消える可能性がある
- ログイン機能はまだない

というモック仕様です。

## v004 関係マップ改善

- 矢印を **紹介元人物 → 紹介先人物** の方向で統一
- 選択人物が属する紹介ネットワーク全体を表示
- ネットワークの起点から、紹介先が放射状・枝分かれ状に広がる配置へ変更
- 同じ世代の人数が増えるほどリング半径を自動拡大し、ノード同士が重なりにくいよう調整
- 選択中人物を濃色で強調
- 起点人物を `START` 表示
- 登録外の紹介元がある場合は点線ノードで表示
- `＋ / − / 全体` のズーム操作を追加
- マウスホイールで拡大縮小、余白ドラッグで移動可能
- マップ上の人物をクリックして選択人物を切り替え可能
