# Connect CRM v011

個人事業主向けの顧客管理モックです。  
人物管理・紹介関係・サービス候補・次回アクション・関係マップ・GAS/Googleスプレッドシート連携を、より実サービスに近い見た目と操作感にUI改善した版です。

## v008での主な改善

- 全体を **SaaS風の情報設計** に再整理
- 左サイドバー + 上部ヘッダーで、現在地が分かりやすい構成へ変更
- ダッシュボードを **行動優先** の見せ方に整理
- 人物一覧・紹介関係・アクション・候補カードの視認性を向上
- 関係マップ画面・連携設定画面のUIを整理
- モーダルフォームを見やすく改善
- レスポンシブ時のレイアウトを調整

## 構成

- `index.html` : 画面本体
- `styles.css` : UIスタイル
- `app.js` : データ処理 / 描画 / GAS連携
- `data/` : サンプルデータ
- `gas/` : Apps Script 用ファイル

## 紹介関係のルール

- 1人の紹介先につき、紹介元は最初の1人だけ記録
- ただし `A → B → C → D` のような紹介の連鎖は保持

## 起動方法

GitHub Pages やローカル環境で `index.html` を開くだけで確認できます。

## GAS連携

`gas` フォルダ内の `Code.gs / Setup.gs / SampleData.gs / appsscript.json` を Apps Script に反映し、`setupConnectCRM()` を実行してください。


## v008 追加改善（スマホ最適化）

- スマホ時は**下部ナビゲーション**寄りの操作感に変更
- テーブルを**縦カード表示**へ切替し、横スクロール依存を軽減
- 文字サイズ・入力欄・ボタンをタップしやすいサイズへ調整
- モーダルを**スマホ全画面**に近い表示へ変更
- 余白と表示幅を調整し、文字ズレや横に広すぎる見え方を改善


## v009 追加改善（ホーム画面の簡略化）

- ホーム画面をスマホ向けにさらに簡略化
- 重要指標 + クイック導線 + 直近アクション中心の構成へ変更
- スマホ時はホーム内の情報量を絞り、スクロール量を削減
- 人物・紹介関係・次回アクションなどは別タブ遷移前提で使いやすく整理


## v010 追加改善（ハンバーガーメニュー）

- スマホ時の各タブ表示を、常時表示の下部ナビから**ハンバーガーメニュー式**へ変更
- 右上 / 左上のメニューボタンから表示・非表示を切替
- メニュー表示中はオーバーレイを敷き、誤操作しにくい構成へ変更
- タブ切替後は自動でメニューを閉じるよう調整


## v011 スマホ実機差の見直し

- スマホで「ホーム以外のタブに移動してもホーム内容が残る」CSS競合を修正
- iPhone / Android向け `viewport-fit=cover` と safe-area 対応を追加
- ハンバーガーメニューのブランド崩れ・空白行を修正
- 横方向のはみ出しを抑えつつ、縦スクロールが止まらないよう overflow 制御を修正
- スマホの人物追加モーダルを画面サイズへ正確にフィット
- 一覧系を初期5件表示 + 「もっと見る」に変更し、長大スクロールを軽減
- 古いモバイルブラウザで差が出やすい `structuredClone` を使わない形式へ変更
- 375×667 / 390×844 / 412×915 / 1440×900 の画面幅で自動チェック済み
